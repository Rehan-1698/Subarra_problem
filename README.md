## 📌 About This Repository

A **subarray** is a contiguous part of an array.

For example, given:

```js
[1, 2, 3]
```

Some possible subarrays are:

```text
[1]
[2]
[3]
[1, 2]
[2, 3]
[1, 2, 3]
```

This repository contains different problems based on this concept and provides practice with loops, arrays, and logical problem-solving.
